# Your first TypeScript program

Let's write a program, compile it, and run it. The whole loop takes seconds.

## Write it

`src/hello.ts`:

```typescript
function greet(name: string): string {
  return `Hello, ${name}!`;
}

const message = greet("TypeScript");
console.log(message);
```

## Types visible already

- `name: string` — the parameter must be a string.
- `: string` after `) ` — this function returns a string.
- `message` — inferred as `string`; the compiler works it out for you.

## Compile and run

```bash
npm run build          # tsconfig emits dist/hello.js
node dist/hello.js

# or with the dev runner
npx tsx src/hello.ts
```

Output:

```
Hello, TypeScript!
```

## The compiled output

Inside `dist/hello.js` you find clean JavaScript — the types removed:

```typescript
// (equivalent compiled output)
function greet(name) {
  return `Hello, ${name}!`;
}
const message = greet("TypeScript");
console.log(message);
```

> [!key] Source of truth stays typed
> You read and edit `src/*.ts`. `dist/*.js` is a build artifact — regenerate
> it, do not hand-edit it.

## Introduce a type error deliberately

```typescript
function greet(name: string): string {
  return `Hello, ${name}!`;
}

greet(42);   // ❌ Argument of type 'number' is not assignable to 'string'
```

```bash
tsc         # error reported, nothing emitted
```

The compiler refuses to emit broken code (by default). The bug is caught
before the program ever runs — that is the whole point.

> [!tip] Keep the loop tight
> `tsc --watch` + `node dist/app.js` gives compile-en-fail in under a second.
> Add a test runner later; for now the compiler is your first test suite.

## A slightly larger idea

```typescript
interface Person {
  name: string;
  age: number;
}

const team: Person[] = [
  { name: "Ada", age: 36 },
  { name: "Grace", age: 45 },
];

function averageAge(people: Person[]): number {
  if (people.length === 0) return 0;
  const total = people.reduce((sum, p) => sum + p.age, 0);
  return total / people.length;
}

console.log(averageAge(team));   // 40.5
```

This already shows interfaces, arrays, and functions typed end to end.
